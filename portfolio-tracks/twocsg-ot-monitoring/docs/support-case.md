# 기술지원 사례 기록 양식

작성 상태: 빈 양식. 아래 항목은 실제 장애 발생·복구 후 채운다.

| 항목 | 기록 |
|---|---|
| 사례 ID / 발생 시각 / 환경 버전 | 미기록 |
| 사용자 증상 / 정상 기대 동작 | 미기록 |
| 영향 범위 / 제어공정 영향 여부 | 미기록 |
| 최초 설정과 최근 변경 | 미기록 |
| 가설 1 / 확인 방법 / 배제 또는 채택 근거 | 미기록 |
| 가설 2 / 확인 방법 / 배제 또는 채택 근거 | 미기록 |
| 근본 원인과 증거 파일 | 미기록 |
| 변경한 설정 / 변경 이유 | 미기록 |
| 복원 방법 | 미기록 |
| 동일 입력 재검증 / 정상 동작 확인 | 미기록 |
| 고객에게 설명할 내용 / 재발 방지 | 미기록 |

증상과 원인을 동일시하지 않는다. 설정 변경을 여러 개 동시에 수행하면 원인을 특정하기 어려우므로 한 번에 한 조건을 바꾸고 기록한다. 성공 화면만 남기지 말고 실패와 성공의 동일 검수 항목을 비교한다.
