# 구축 설계 및 인수시험

## 대상·경계

소유한 OpenPLC/FUXA 가상 환경과 공개용 PCAP만 사용한다. 회사 로그·IP·계정·탐지 규칙을 가져오지 않는다. 운영 설비에 센서를 연결하거나 능동 탐색하지 않는다.

```mermaid
flowchart LR
  HMI[FUXA] -->|Modbus TCP 5020| PLC[OpenPLC]
  PLC -. PLC namespace에서 수동 관찰 .-> Capture[캡처]
  Capture --> PCAP[PCAP]
  PCAP --> Sensor[오프라인 센서 분석]
  Sensor --> Logs[이벤트 및 경보 로그]
  Logs --> Report[검수 및 기술지원 보고]
```

실시간 단계는 실제 수집을 검증한 뒤 추가한다. 다른 컨테이너를 같은 bridge에 연결하는 것만으로 unicast 전체가 보이지 않는다. 이 축소 실습의 namespace 관찰과 현장 SPAN/TAP 배치는 구분한다.

## 사전 학습을 작업과 연결

| 필요한 지식 | 실습에서 확인할 것 | 설명 가능한 역량 |
|---|---|---|
| client/server, TCP, bridge | 어느 IP가 요청하고 어디서 캡처해야 하는가 | 네트워크 구성 및 수집 장애 분석 |
| Modbus 기능코드·주소 | FC01/03 읽기와 FC05 쓰기를 원본에 대조 | 프로토콜 분석 |
| 프로세스·로그·볼륨 | 센서 실행과 정상 분석을 따로 확인 | 운영체제·서비스 점검 |
| 입력·규칙·출력 검수 | 패킷 존재, 프로토콜 식별, 규칙 적중, 로그 저장 단계 | 기술지원 원인 분리 |

## 인수시험표 — 전 항목 미실행

| ID | 시험 | 기대 결과 | 수집 증거 |
|---|---|---|---|
| B-01 | 설치/버전/설정 유효성 | 선택 버전 식별, 설정 검사 성공 | 설치 로그·버전·설정 해시 |
| B-02 | 기존 정지 PCAP 입력 | 읽기 트래픽 식별, FC05 경보 없음 | 입력 해시·분석 로그 |
| B-03 | 기존 운전 PCAP 입력 | 정상 ON/OFF 쓰기 두 요청의 이벤트 대조 | 원본 패킷 시각·SID·이벤트 |
| B-04 | 5020 비표준 포트 인식 | Modbus 분석 여부 실측 | 프로토콜 설정·출력 |
| B-05 | 가상망 수동 수집 | HMI→PLC 트래픽 확보, 센서가 제어 쓰기를 보내지 않음 | 캡처 위치·PCAP |
| B-06 | 경보 의미와 오탐 | 정상 HMI 쓰기를 공격으로 단정하지 않음 | 정상 허용 출발점 정책·분석 |
| B-07 | 센서 재시작 | 설정·로그 보존, 이후 분석 재개 | 전후 로그·동일 입력 비교 |
| B-08 | 백업 복구 | 새 출력 폴더에서 설정 복구 후 같은 입력 결과 대조 | 해시·복원 절차·결과 |

기존 운전 PCAP은 정상 HMI 쓰기이므로 비인가 공격 탐지의 양성 표본이 아니다. 출발점 정책 위반 탐지를 주장하려면 별도 승인된 가상 client PCAP과 역할 증거가 필요하다. 이를 확보하지 못하면 기능코드 이벤트 검증으로 범위를 제한한다.

## 설치 단계에서 확정할 항목

- 안정 릴리스와 이미지 출처·digest, CPU/RAM 요구
- 선택 릴리스의 Modbus parser 활성화·5020 처리 방법
- EVE 출력 및 필요한 이벤트 타입 지원 여부
- 자체 규칙 문법 검사 후 원본 PCAP 대조; 룰 적중 수를 미리 성공 수치로 기록하지 않음
- 원본 입력 read-only, 출력은 실행 ID별 별도 폴더
- 권한은 캡처에 필요한 범위로 제한; 초기 단계는 네트워크 송신 없는 파일 분석

## 의도적 장애 실습 — 아직 발생·해결하지 않음

1. **잘못된 입력 또는 수집 위치**: 패킷 파일/인터페이스, TCP 5020 관찰 여부, 센서 입력 순으로 확인. 센서가 실행 중이라는 이유로 수집 정상으로 판정하지 않는다.
2. **프로토콜 또는 규칙 설정 오류**: PCAP에 쓰기가 있는데 이벤트가 없을 때 parser 인식, 규칙 활성화, 방향·주소 조건, 로그 출력을 차례로 확인한다. 설치 버전에서 실제 재현되는 오류만 사례로 남긴다.

## 운영 인계 기준

센서 상태, 마지막 이벤트 시각, 로그 저장 공간, 설정 변경 이력, 입력 손실 지표의 지원 여부를 정리한다. 센서 중단은 제어 중단과 별도로 처리한다. 수집이 끊겼을 때는 원인 해결 전 탐지 공백을 명시한다. 지원 요청 자료에는 버전·시각·오류·관련 최소 PCAP을 포함하고 인증정보를 제외한다.
