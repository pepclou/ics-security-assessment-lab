# 투씨에스지 지원용 — OT 트래픽 모니터링 구축·기술지원 실습

상태: 별도 프로젝트 설계 및 인수시험 준비. 센서 설치·탐지 성공·장애 해결 실적은 아직 없다.

## 목적

사용자가 제공한 보안솔루션(OT) 설치·구축·기술지원 공고를 기준으로, 수집 지점 선정 → 설치 → 트래픽 수집 → 탐지 확인 → 장애 진단 → 운영 인계를 보여준다. 기존 인더포레스트 프로젝트의 가상 PLC/HMI와 정상 PCAP은 출처를 명시해 시험 입력으로 재사용한다. 기존 진단 성과를 새 구축 성과로 중복 주장하지 않는다.

## 구현 범위

1. 기존 PCAP으로 오프라인 분석 환경을 먼저 검증한다.
2. 수동 감시 센서를 가상 PLC의 실제 트래픽 관찰 위치에 배치한다.
3. 정상 읽기와 정상 쓰기를 구분하고, 출발점 정책을 포함한 경보의 의미를 설명한다.
4. 설정 오류 2건과 복구 결과를 직접 재현해 기술지원 기록을 남긴다.
5. 설치 가이드·검수표·설정 백업·복구·고객 인계 문서를 작성한다.

## 도구 결정

Nozomi·TXOne은 공고와의 연관성을 공부하는 대상으로 두며 실습 라이선스·이미지 확보는 미확인이다. 공개 페이지의 데모 요청을 무료 실행 이미지 제공으로 간주하지 않는다. 외부 업체에 문의를 발송하지 않았다.

실습 후보는 Suricata 기반 수동 분석이다. 현재 문서에서 Modbus 기능코드 규칙과 PCAP 입력 기능을 확인했다. 실제 사용할 안정 버전·배포 이미지·설정은 설치 단계에서 확인하고 고정한다. 상용 제품의 자산 식별·위험도 기능과 동등하다고 주장하지 않는다.

## 최종 제출물의 구성

- 1쪽 요약: 요구사항, 구성, 설치·검수 결과, 직접 해결한 장애
- 설치서: 버전, 인터페이스, 수집 위치, 로그 경로, 검증 명령
- 검수 증거: 정상 읽기와 쓰기, 경보, 데이터 누락 여부, 재시작 복구
- 장애 사례 2건: 증상·가설·관찰·원인·수정·재검증
- 운영 인계: 일상 점검, 알람 해석, 설정 백업·복구, 지원 요청 시 필요한 자료

현재는 결과가 없는 준비 문서이므로 완료 포트폴리오나 제품 경험으로 제출하지 않는다.
